# NEON VOID

霓虹风格的 2D 割草生存游戏（单文件，零依赖）。

## 怎么玩

直接**双击 `index.html`** 用浏览器打开即可（Chrome / Edge 均可）。

- **WASD / 方向键** — 移动
- **自动开火** — 武器自动索敌，你只负责走位
- **空格 / Shift** — 冲刺（无敌帧，躲弹幕和围堵的关键）
- **1 / 2 / 3** — 升级选卡，**R** 重随机
- **ESC** — 暂停，**M** — 静音
- 手机/触屏：左半屏拖动 = 虚拟摇杆，右侧点按 = 冲刺

## 进化系统（核心机制）

每把武器升到 **LV5** 且配对被动 ≥LV3 后，升级卡或精英/Boss 掉落的**宝箱**会触发进化：

| 武器 | 配对被动 | 进化形态 |
|---|---|---|
| 脉冲炮 | 超频 | **RAILGUN** — 贯穿整条线的超高速弹 |
| 环刃 | 伺服腿 | **SAWBLADE STORM** — 8 把呼吸锯刃，减速 |
| 新星冲击 | 反应堆 | **SUPERNOVA** — 双重冲击波，超大击退 |
| 连锁闪电 | 磁力核心 | **TEMPEST** — 12 连弧并眩晕 |
| 无人机 | 纳米再生 | **SWARM CARRIER** — 6 机 3 连发穿甲弹 |
| 灼烧光环 | 合金装甲 | **INFERNO WARD** — 巨型灼烧领域 + 群体吸血 |

## 局外成长

- 每局按存活时间 / 击杀 / Boss / 宝箱结算**金币**
- **ARMORY** 商店：8 项永久升级（伤害/速度/血量/磁力/经验/金币/重随机/**复活**）
- **3 名角色**：VESPER（均衡）/ AXIOM（脆皮高伤，60 币）/ BASTION（重装，100 币）
- 通关解锁 **NIGHTMARE** 难度

## 目标

- **2:30** THE WARDEN → **5:20** THE DEVOURER → **8:00** VOID CROWN
- 分钟级刷怪事件（波次环 + 精英包）会打断你的节奏
- Boss 存活越久越狂暴——别想永远放风筝

## 测试用参数（可选）

`?bot=1` 自动试玩 · `&fast=5` 加速 · `&god=1` 无敌 · `&t=150` 跳时 · `&boss=1` 直出 Boss

## 技术说明

纯 Canvas 2D + WebAudio 合成音效/音乐（Boss 战有加厚层），无外部资源或依赖；存档 localStorage。空间哈希碰撞、子步进物理、预渲染精灵贴图、密集怪群 LOD；满怪（400+）实测每帧 ~2-4ms。
